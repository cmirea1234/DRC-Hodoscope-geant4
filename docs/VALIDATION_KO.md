ROOT 검증은 사건 수/트리거 누적, 128채널 매핑과 threshold 판정, 광자 등록·종료 집계 일치, 설정값과 파일 종료 상태 등을 검사합니다. 기준 묶음 해시 검사(`verify_bundle.py`)와 CTest만 통과한 것은 위 실행 시험 전체를 통과한 것과 다릅니다.

5,000트리거의 [공개 요약](../reference/knu_muons_5000_summary.json)에는 seed별 수치와 ROOT 해시가 있습니다. 전체 ROOT와 실행 로그는 검증 서버에 보존돼 있으며 Git에는 포함하지 않았습니다. 각 잡 시간은 약 1시간39분~5시간43분, 전체 완료까지 약5시간43분이었습니다. 노드 부하·seed 차이가 있으므로 이후 실행 시간의 보장은 아닙니다.

## original을 선택한 이유

light32는 H1 원통 표면을 다각형으로 근사하는 등 형상 표현이 다릅니다. 기존 500트리거 비교에서 실행 시간은 줄었지만 검출 p.e.가 original 27,084에서 light32 19,644로 감소했습니다. 선택 사건도 완전히 같지 않아 단순히 같은 사건의 응답비로 해석하지 않습니다.

별도 H1X 공통 광자 시험에서는 450 nm 광자 3,200개 중 SiPM 도달 수가 original 322, light32 199였습니다. 대표 경계 추적에서는 표면 법선 차이로 전반사가 깨지고 광자가 이탈하는 사례를 확인했습니다. 따라서 속도 이득만으로 light32를 original과 동등한 대체 모델로 사용하지 않습니다. 이 결론이 original의 절대 물리 정확성을 인증하는 것은 아닙니다.

## 현재 사용할 범위

- 기존 original 우주선 배치: source z=150 mm, target_backproject, modified_gaisser_joint, 0.2~1,000 GeV, 천정각 최대45도. 매크로의 기존 재료·광학·노이즈·PDE·threshold를 유지합니다.
- 뮤온 한 잡의 목표는 1~500 **T1&T2 트리거**입니다. 고통계는 서로 다른 seed로 분할합니다. 기존 설정은 T1&T2를 만족하지 않는 사건의 광학 추적을 생략합니다.
- 현재 지표의 T1&T2 조건은 각 트리거 Edep≥0.05 MeV입니다. 직접 입사 뮤온만의 엄격한 관통 조건이나 검출기 고유 효율과 동일하지 않습니다.
- 모듈 확장: T1/T2/H1/H2의 위치/회전을 각각 설정합니다. 변경 배치는 명시적 빔 또는 고정 광자 입력에 한정합니다. 회전 배치에 기존 cosmic 타기팅을 사용하려 하면 중단합니다.
- 전자빔 도구는 현재 pencil e- 1~100 생성 사건을 지원합니다. 이는 구현상의 범위이며 이 모든 에너지/배치/사건 수가 검증됐다는 뜻은 아닙니다.
- Cerenkov는 기존 기준대로 비활성입니다. 전자빔의 실제 광량을 주장하기 전에 이 조건을 포함해 물리 모델을 검토해야 합니다.

## 아직 확인하지 않은 것

실측 검출기 데이터와의 일치, 모든 에너지·입사각에서의 정확성, 새 설치 배치 전체의 부품 겹침, 실제 빔 폭·발산·상류 물질·자기장, 다른 Geant4 버전/플랫폼은 별도 검증 대상입니다. building/추가 트리거/lite 설정은 새 모듈 배치 인터페이스의 지원 범위 밖입니다.

새 배치에서는 기존 ROOT의 명목 Z/yaw 및 `v21_geometry_map` source 좌표만으로 최종 월드 배치를 해석하지 않습니다. `INPUT.json`, `layout_placements.jsonl`과 활성화한 validation map을 확인합니다.

첫 설치 또는 코드 변경 후에는 5트리거 → 500트리거 → 독립 seed 분산 실행 순서로 확인합니다. 다른 환경에서 기준 수치가 달라지면 차이를 기록하고 원인을 확인하며, 수치를 맞추기 위해 물리 파라미터를 조정하지 않습니다.
